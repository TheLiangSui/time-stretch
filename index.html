快捷键与操作

全部操作都可以用键盘完成

拖拽空白处新建矩形拉伸层（按住 Shift 反向拉伸）
点击矩形 / 图层行选中该层
Alt + 点击矩形穿透到下一层（矩形重叠时用）
拖拽矩形内部移动（自动吸附 6px；锁定的层不能拖）
拖拽 8 个控制点改变大小
左右拖数值前的小图标连续改数值（Shift ×10、Alt ×0.1、双击回默认值）
Delete删除选中层
Ctrl+C / X / V复制 / 剪切 / 粘贴图层（连续粘贴自动错开）
Ctrl+Shift+V从系统剪贴板粘贴图片
Ctrl+D / Ctrl+Shift+K原地复制一层 / 导入图片
Ctrl+Z / Ctrl+Shift+Z撤销 / 重做（焦点在参数框里也有效）
[ / ]图层下沉 / 上浮
Shift / Ctrl+点击图层行多选；Shift 是「从上次点的那行到这里」整段选
图层区空白处拖动框选：矩形扫过的行进入选择
Shift / Ctrl+点画布上的图层直接在画布上增减选择
拖动图层行 / 组头调整前后顺序；拖组头 = 整组一起挪
Ctrl+G / Ctrl+Shift+G成组 / 解散合集
Ctrl+M合并选中的多个图层为一个形状
E / L显示隐藏 / 锁定位置
R随机选中层的饱和度 / 冷暖度
方向键 / Shift+方向键选中层位移 1px / 10px；未选中时改为平移画布
Esc退出输入框 / 取消选中 / 取消正在绘制的框
Ctrl+滚轮以指针为中心缩放
滚轮 / Shift+滚轮上下平移 / 左右平移画布
右键拖拽 / 空格拖拽 / 中键拖拽平移画布
拖动右下角小地图平移画布（最省事）
Ctrl+0 / Ctrl+1适应窗口 / 原始像素（Shift+1 / Shift+0 同效）
Ctrl+\隐藏 / 恢复两侧面板，只看画面
?打开这个面板
Ctrl+S / Ctrl+Shift+S保存到项目库 / 导出 .json
Ctrl+O打开工程文件
Ctrl+,打开设置（默认目录）
